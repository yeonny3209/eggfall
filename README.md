# EGGFALL

드래곤 오픈월드 MMO — 기획서 v0.2 구현

> 모든 용은 서로 다른 스킬을 갖고, 세계에는 단 열두 개의 신성이 있으며, 그 열둘은 언제나 사냥당할 수 있다.

## 현재 상태: **Phase 0 · Phase 1 완료**

**§2 핵심 루프가 끝까지 돕니다.**

```
탐색 → 회수(E) → 운반(이동 −25%) → 둥지 귀환 → 흡수 → 성장 → 외형 변화
```

- **Phase 0 (비행)** — 처음엔 관성·실속·스태미나가 있는 항공기식 모델이었지만, 조작이 너무 어렵다는
  피드백을 받아 **훨씬 쉬운 스펙테이터 캠 모델**로 바꿨습니다: 마우스가 보는 방향이 곧 날아가는
  방향이고, 스태미나·실속·상승기류는 없습니다.
- **Phase 1 (알)** — 자연 둥지 64곳에서 알이 스폰되고, 주워서 홈 둥지로 가져가 흡수하면 성장합니다.

전투·네트워크는 아직 없습니다 (Phase 2~3).

## 구현된 것

**비행 모델** (`src/flight/simulate.ts` — Three.js 의존 없는 순수 함수)

- "스펙테이터 캠" 모델: 마우스가 정한 목표 시점을 실제 자세가 뒤쫓는다.
  성장 단계별 `turnPenalty` 가 그 추적 속도를 늦춰 **큰 용일수록 시점 반응이 굼떠진다** (§6.3 불변 규칙 유지).
- 목표 속도로 부드럽게 가감속한다 (순간 정지/출발이 아니다).
- A/D 는 시선의 피치와 무관하게 항상 수평으로만 이동 — 위를 올려다봐도 강제로 뜨지 않는다.
- 실제 지형과 충돌해 착지/이륙한다.

**알 스폰** (`src/egg/spawn.ts` — 역시 Three.js 의존 없는 순수 함수)

- 자연 둥지 64곳은 **시드에서 결정론적으로** 생성된다. 위치를 저장할 필요가 없고, 서버·클라가 같은 월드를 본다.
- 한 둥지에 알은 최대 하나. 주우면 5~15분 뒤 리스폰한다 (§7.1).
- 등급은 가중 랜덤(일반 1000 : 고급 380 : 희귀 110 : 영웅 26). **신성 알은 자연 둥지에서 나오지 않는다** — 시즌당 12회 각성 전용 (§5.1).
- 등급이 유전 질량과 특성 수를 결정한다. 특성은 흡수 시 스킬 발현 풀의 재료가 된다 (§4.4).
- 난수 상태를 `SpawnerState` 에 담아 그대로 직렬화 가능 — 오프라인 후 재접속해도 경과 시간만큼 알아서 채워진다.

**운반 · 흡수 · 성장** (`src/player/progress.ts` — 순수 함수)

- 알은 **한 번에 하나만** 들 수 있고, 드는 순간 이동속도가 −25% 된다 (§2 게임의 중심축).
  운반 중에는 드래곤 앞발에 알이 실제로 보인다.
- 월드 중앙 **홈 둥지**로 돌아가 1.8초 채널링하면 흡수된다. 둥지는 알을 들고 있을 때 더 밝게 빛난다.
- 흡수하면 세 가지가 동시에 일어난다: 유전 질량 누적 → 단계 판정 / 속성 친화도 누적 → 외형 변화 /
  특성이 발현 풀에 축적 → Phase 4 스킬 생성기의 재료.
- **성장은 오직 유전 질량 총합으로만 결정된다** (§6.1). 임계값 `[0, 50, 180, 500, 1200, 2600]`.
- 친화도에 따라 순혈(70%+) / 이종(40·40) / 잡종으로 갈린다 (§3.5).

**외형 변화** (§6.2 — 저장하지 않고 결정론적으로 계산)

- 몸집이 단계별 배율로 커지고, **등 가시가 단계 수만큼 늘어난다** — 숫자 UI 없이 성장이 실루엣으로 읽힌다.
- 비늘 색은 누적 친화도의 가중 혼합. 뇌풍 위주로 먹으면 보랏빛, 반석 위주면 흙빛이 된다.
- 단계가 오르면 선회 반응도 함께 둔해진다 (§6.3 불변 규칙).

**월드** (`src/world/`)

- 8km × 8km 절차 지형. **렌더 메시 · 충돌 · 그림자가 모두 같은 `terrainHeight()` 를 쓴다** (`terrain.ts`).
- 랜드마크 첨탑 240개 — 속도감의 근거.
- 고층 경계에 구름층, 그라디언트 하늘, 지면 그림자.
- 알은 속성 색으로 빛나고 위아래로 떠다니며, **희귀 이상은 빛기둥**을 세워 멀리서도 보인다 (`eggs.ts`).

**HUD** (`src/ui/hud.ts`)

- 속도 · 고도 · 층 표시, 착지 알림, 고속 스트릭 효과
- **알 파인더** — 가장 가까운 알의 등급·속성·거리와 기수 기준 방향 화살표, 고도차(▲▼), 주변 개수

### 설계 원칙 (§13 지침 준수)

1. **타입 우선** — `src/types.ts` 가 계약. 여기 없는 개념은 존재하지 않는 것으로 취급.
2. **순수 함수 분리** — `simulate.ts` / `terrain.ts` 는 렌더링·네트워크와 무관. Phase 2 에서 서버가 그대로 재사용한다.
3. **시뮬레이션 ↔ 렌더링 분리** — 시뮬레이션은 고정 timestep(1/60), 렌더링은 rAF. 프레임률이 물리 결과를 바꾸지 않는다.
4. **모든 수치는 `balance.json`** — 코드 수정 없이 튜닝 가능.
5. **12신성은 데이터** — `divines.json`. 하드코딩하면 유지보수 불가.

### 개발용 콘솔 핸들

개발 빌드에서 `window.__eggfall` 로 상태를 들여다볼 수 있습니다.

```js
__eggfall.pause()      // 시뮬레이션 정지
__eggfall.pump(3)      // 3초분 수동 진행
__eggfall.state        // FlightState
```
